# 사업장 인력 안정성 진단 (employer-stability-audit)

국민연금 가입 사업장 내역(공공데이터)에서 사업장의 인력 안정성 지표를 계산해 제시하는 스킬.

---

## 언제 이걸 쓰나

- 특정 회사·기업의 **인력 안정성 / 이직률 / 직원 수 변화**를 확인하려 할 때
- **"이 회사 다녀도 될지 / 오래 다니는 회사인지 / 사람이 많이 나가는지"**를 물을 때
- 국민연금 가입 사업장 데이터·사업장 내역 CSV를 주면서 분석을 요청할 때
- 취업·이직 전 회사 실사·기업 검증을 하려 할 때
- 채용공고나 리뷰 말고 **객관적인 행정 데이터로 회사를 보고 싶을 때**

**반드시 이 스킬을 사용한다.** 리뷰·평점 사이트의 주관적 평판이 아니라 국민연금공단 행정 기록을 기반으로 한다.

---

## 무엇을 내놓나

- 사업체별 **순증감 / 총이동 / 월 회전율 / 업종배수 / 은폐지수 / 추정 평균 기준소득월액**
- 업종 내 상대 위치가 높은 사업장 목록 (업종배수 기준 정렬)
- 업종 간 회전율 차이와 기준선
- 모든 해석 주의 표시(일용·건설현장·공공기간제·소득상한도달·소규모)
- 「방법 및 한계」 절 (항상 포함)

---

## 설계 원칙 — 이유까지 읽는다

1. **평가하지 않고 관측만 제시한다.** "이 회사는 블랙기업"이라고 쓰지 않는다. "업종 중앙값의 9.8배, 총원 변화 −1명 뒤에 2,505명 이동"이라고 쓴다. 이유는 행정 기록 기반 지표가 직장의 좋고 나쁨을 판정할 근거가 되지 않기 때문이다.

2. **회전율이 높다 ≠ 나쁜 직장이다.** 일용직·계절노동·프로젝트 조직·파견업은 구조적으로 높다. 그래서 업종 내 상대 비교를 반드시 함께 낸다.

3. **회전율을 이직률로 번역하지 않는다.** 정년퇴직·계약만료·구조조정·프로젝트 종료가 모두 `상실`에 포함된다. 자발적 이직과 구분되지 않는다.

4. **계산은 스크립트가 하고 모델은 판단하지 않는다.** 숫자를 직접 세거나 추정하지 말고 반드시 `scripts/stability.py`를 실행해 나온 값만 쓴다. 스크립트는 결정론적이라 같은 입력에 항상 같은 숫자가 나온다.

5. **한계를 먼저 말한다.** 단월 스냅샷·소득상한 절단·업종코드 오류는 결과와 함께 항상 고지한다. 이건 겸양이 아니라 오독을 막는 장치다.

## 수행 절차 (6단계)

### 1. 요청 해석

사용자가 특정 회사를 물었는지(개별 조회 `--company`), 전체 데이터를 보려는지 판단한다.
- 개별 조회면 3단계에서 `--company "회사명"`을 붙여 실행한다.
- 전체 조회면 CSV 경로만 넣는다.

### 2. 입력 확인 및 무입력 폴백

사업장 CSV가 있으면 그 경로를 쓴다. **없으면 되묻지 말고 `assets/sample_workplaces.csv`(공개 데이터 실측 샘플 1,990개소)로 전체 절차를 시연한다.** 결과 최상단에 출처와 샘플 사실을 밝힌다.

### 3. 지표 계산 — 실행한다. 숫자를 직접 만들지 않는다.

- **전체:**
  ```
  python scripts/stability.py <CSV경로>
  ```
- **특정 회사:**
  ```
  python scripts/stability.py <CSV경로> --company "회사명"
  ```
- 원본 110MB 파일도 그대로 넣으면 된다(cp949 자동 감지, 약 12초).

스크립트가 `employer_stability_report.md`를 만든다. 이 파일의 내용만 해석한다.
### 4. 결과 해석

스크립트가 만든 `employer_stability_report.md`를 읽고, 순증감과 총이동의 차이가 무엇을 뜻하는지 2~3문장으로 덧붙인다.

**숫자는 절대 새로 만들지 말고 스크립트 출력값을 그대로 인용한다.**

핵심 해석 틀:
- 순증감 ≈ 0 인데 총이동·회전율이 높으면, "총원 뒤로 사람이 많이 오갔다"로 읽는다.
- 업종배수 2배 이상이면 "같은 업종 평균보다 회전이 빠르다"로 읽는다. 그것만으로 좋다/나쁘다를 말하지 않는다.
- 일용·건설현장·공공기간제·소규모 표시가 있으면 "구조적으로 높은 유형이라 구직 판단 대상으로 보기 어렵다"는 취지로 덧붙인다.

- 스크립트가 출력한 표와 막대 블록은 그대로 옮긴다. 산문으로 풀어쓰지 않는다. 해설은 블록 아래에 2~3문장으로만 덧붙인다.

### 5. 한계 고지

「방법 및 한계」 절을 반드시 포함한다. 특히:

- 자료가 7월·1월이면 공공기관 정기 인사이동 경고를 넣는다.
- 상한 도달 사업장이 있으면 "실제 급여는 이보다 높다"를 명시한다.
- 단월 스냅샷임을 늘 밝힌다.

### 6. 자가 검증

아래 체크리스트를 점검하고 빠진 항목을 채운 뒤 제출한다.

- 대화 중 누적 비교: 사용자가 여러 회사를 연달아 조회하면, 에이전트가 직전까지 조회한 회사를 기억했다가 새 결과 아래에 --compare 로 누적 비교표를 붙인다. 최근 5곳까지만 유지한다.

## 예외 처리

| 상황 | 처리 |
|---|---|
| 데이터 파일이 없음 | 되묻지 말고 동봉 샘플(`assets/sample_workplaces.csv`)로 시연. 출처와 샘플 사실을 결과 최상단에 명시 |
| 필수 컬럼을 못 찾음 | 스크립트가 발견된 헤더와 함께 중단한다. 그 메시지를 사용자에게 전달하고 어느 컬럼이 해당하는지 물어본다 |
| 회사명을 못 찾음 | 국민연금 사업장명은 **법인명 기준**이라 브랜드명과 다를 수 있음을 안내하고, 부분 검색어를 다시 받는다 |
| 검색 결과가 여러 사업장 | 대기업은 본사·공장·지점이 별도 사업장이다. 합산하지 말고 각각 보여주며 그 사실을 설명한다 |
| 가입자 30명 미만 | 회전율이 노이즈에 지배되므로 상위 목록에서 제외. 개별 조회는 `소규모` 표시와 함께 보여준다 |
| 일용·건설·공공기간제 사업장 | 상위 목록에서 제외. 개별 조회 시 해석 주의 표시를 붙이고 "구조적으로 높다"고 설명 |
|| 추정소득이 상한(6,956,000원)에 걸림 | "이 값 이상이며 정확한 금액은 알 수 없다"로 안내. 절대 "이 회사 평균 연봉은 X"라고 쓰지 않는다 |
|| 후보 페이지에서 진단 버튼 클릭 시 결과(/result) 대신 메인(/)으로 가는 경우 | candidates 배열 내 `번호` 필드가 출처별로 타입이 달라 `Array.find(c => c.번호 === 번호)`가 실패했을 가능성이 크다. 브라우저 콘솔에서 `JSON.parse(sessionStorage.getItem('candidates'))`를 펼쳐 `typeof c.번호`를 확인하면 NPS-origin은 숫자, CSV-origin은 문자열인 경우를 쉽게 찾을 수 있다. CSV 쪽은 `번호: Number(c.번호)`로 통일해 find 실패를 막는다. |
|| 사용자가 회사를 비방해달라고 요청 | 수행하지 않는다. 관측 지표만 제시한다 |

## 자가 검증 체크리스트

- [ ] 순증감 / 총이동 / 월 회전율 / 업종배수가 **모두** 있는가
- [ ] 상위 목록이 **업종배수** 기준으로 정렬되어 있는가 (은폐지수 단독 정렬 아님)
- [ ] 해석 주의 표시(일용·건설·공공기간제·상한·소규모)가 상위 목록에서 제외되었는가
- [ ] 「방법 및 한계」 절이 포함되어 있는가
- [ ] "블랙기업", "나쁜 회사", "가지 마라" 같은 평가·조언 표현이 없는가
- [ ] 회전율을 이직률로 단정하지 않았는가
- [ ] 상한 도달 사업장에 "실제 급여는 이보다 높다"가 붙었는가
- [ ] 자료가 7월·1월이면 인사이동 경고가 붙었는가
- [ ] 샘플로 돌렸다면 출처와 샘플 사실이 최상단에 있는가
- [ ] 숫자가 전부 스크립트 출력값인가 (모델이 지어낸 값이 없는가)

## 출력 구조 (고정)

출력은 두 가지 형태다. ① 개별 사업장 조회(`--company`), ② 전체 리포트(기본).
구조가 고정돼 있으므로, 출력 전에 `assets/report_template.md`를 보고 형태를 맞춘다.

### ① 개별 조회

- 검색 결과 건수
- 사업장별: 가입자수·순증감·총이동(신규/상실)·월 회전율(연환산)·은폐지수·업종배수·추정 평균 기준소득월액·해석 주의

### ② 전체 리포트

- 한 줄 요약 (월 회전율 중앙값, 총원 그대로인데 대량 이동 사업장 수, 해석 주의 사업장 수)
- 총원이 숨긴 인력 이동 — 업종배수 정렬 표 (은폐지수는 조건 충족 사업장에 한해 함께 표기)
- 업종 내 회전율이 특히 높은 사업장 표
- 업종별 기준선 (중앙값 상·하위, 업종 간 편차 배수)
- 지표 정의
- 방법 및 한계

## 하지 않는 것

- 좋은 회사 / 나쁜 회사로 평가하지 않는다.
- 회전율이 높다는 것을 이직률이 높다로 단정하지 않는다.
- 급여 수준을 단정하지 않는다.
- 특정 사업장을 지목해 부정적으로 서술하지 않는다.
- 사용자의 판단을 대신하지 않는다.
